# Another OpenCode Plugin for Obsidian v0.4.0

This release adds OpenCode v2 compatibility for servers started by the plugin.

## Compatibility

- OpenCode v2 `serve` always generates a random password and requires HTTP
  Basic auth. Previously every plugin request against a v2 server was rejected
  with `401 Unauthorized`.
  - The plugin now reads the `server password <pw>` line from the server's
    stdout and sends `Authorization: Basic opencode:<password>` on API
    requests, the event stream, and the health check.
  - V1 servers are unaffected: they print no password line, so no auth header
    is sent and behavior is unchanged.
- Updated the documented custom-command template: OpenCode v2 removed
  `--shutdown-after-last-client` (its attach semantics are built in).

## Known limitation

- The embedded web UI iframe still authenticates like any browser request.
  Whether the v2 login/prompt flow works inside Obsidian is still under
  verification; API-level functionality works without it.

## Installation

BRAT users can install or update from:

```text
jensenojs/another-opencode-for-obsidian
```

The release includes:

- `manifest.json`
- `main.js`
- `styles.css`
