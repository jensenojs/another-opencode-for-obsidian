# v0.5.2

## 修复

- opencode v2.0.8 移除了 `/api/health` JSON 端点，导致启动探活 45s 超时、server 被误杀。健康探测改为多端点回落：`/api/health`（v2.0.3）→ `/api/config`（v2.0.8+，JSON + 鉴权探针）→ `/global/health`（v1）。
- 已知陷阱：v2.0.8 的 `/health` 返回 SPA HTML 假 200，不可用作探针。

## 说明

- opencode 配置 `update: "auto"` 会静默升级二进制，API 漂移可能再次破坏插件；版本号在新端点无法精确获取时按 major=2 推断，仅用于 v2 深链路由判定。
